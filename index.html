What's inside

~1,000 lines on the Node standard library. The container is the sandbox; the loop is just a REPL with hands.

runner.js — drop-in contract

ContainerInput on stdin, sentinel-delimited ContainerOutput on stdout. Identity files, memory/*.md, IPC polling — identical to the default runner.

api.js — fetch, nothing else

Anthropic Messages API with retries, backoff, and prompt caching via cache_control. Works with ANTHROPIC_BASE_URL proxies.

loop.js — the agent loop

Send, execute tool calls, append results, repeat. Context trimming keeps long sessions under the window.

tools.js — six core tools

bash, read_file, write_file, edit_file, glob, grep — unrestricted inside the container, because the container is the boundary.

jsclaw-tools.js — IPC, no MCP

send_message, schedule_task and friends as plain in-process functions writing atomic JSON files the host watcher picks up.

session.js — sessions are JSON

A session is the raw messages array on disk. Resume is a file read. No daemon, no database.

Quick start

Build the image and point jsclaw at it — or run it bare for development.

# Build the container
git clone https://github.com/jsclaw/agent-micro && cd agent-micro
docker build -t jsclaw-agent-micro:latest -f container/Dockerfile .

# Point jsclaw at it
npx jsclaw config set containerImage jsclaw-agent-micro:latest

# Or standalone, no container
export ANTHROPIC_API_KEY=sk-ant-...
echo '{"prompt": "list the files here"}' | node runner.js
